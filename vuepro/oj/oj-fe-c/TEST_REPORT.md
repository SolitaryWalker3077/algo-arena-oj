## 兼容性与性能

- Vite 构建目标固定为 Chrome 90、Firefox 88、Safari 14、Edge 90。
- 移除 Element Plus 全量注册，改为组件按需引入和路由级代码拆分。
- 卡片图片启用原生懒加载与异步解码；列表请求支持缓存、并发合并和取消过期请求。
- Chromium 已完成实际交互测试；Firefox、Safari、Edge 本次环境未提供对应浏览器，完成构建目标校验但未做真机回归。

## 接口边界说明

当前后端仓库已提供竞赛列表、报名和“我的竞赛”接口，但尚未提供 C 端题目作答、练习题目和排名数据接口。因此本次已完成这三个按钮的状态校验、竞赛 ID 传递和独立页面路由；目标页保留了后续接口接入位置，不伪造正式业务数据。
